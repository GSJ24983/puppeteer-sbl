How this works

Left pane is content. The engine is frozen and lives inside this file. Preview runs the real engine in an iframe, so what you see is byte-for-byte what exports. Export gives you one self-contained HTML - offline, no dependencies, mail it to anyone.

Cmd/Ctrl + Enter re-runs the preview.

Scenario shape

{
  "deckTitle": "The Puppeteer",
  "scenarios": [{
    "id": "signoff",              // slug, appears in the session code
    "title": "...", "kicker": "...", "tag": "Business analysis",
    "meta": "6 min - 3 decisions", "thumb": "office",
    "blurb": "One sentence of tension.",
    "highlight": false,           // true = teal pill on the hub card
    "steps": ["Briefing","Decision","Write it down","Debrief"],
    "start": "brief",
    "nodes": { ... },
    "endings": { ... }
  }]
}

One scenario in the array and the hub is skipped - it opens straight into the run. Several, and you get a hub of cards.

Node types

narrative - sets the scene, one Continue button.

{"type":"narrative","step":0,"scene":"office","eyebrow":"Briefing",
 "title":"...","text":"...","media":[],"to":"n1"}

choice - the core mechanic. Each choice may carry a consequence screen before it routes on.

{"type":"choice","step":1,"scene":"office","prompt":"...",
 "gate": false,                  // true = wrong answers disable and retry, no advance
 "choices":[
   {"k":"A","label":"...","sub":"...","tag":"Signed as-is","chip":"Signed",
    "correct": false,            // only meaningful when gate:true
    "lesson":"coaching note shown on a gated wrong answer",
    "consequence":{"scene":"storm","title":"...","text":"...",
                   "lesson":"what this cost you","good":false},
    "to":"n2"}]}

multi - multi-select, rules-graded against correct indexes. No partial credit routing; it always continues to to, but the feedback names what was missed.

{"type":"multi","step":2,"scene":"matrix","prompt":"...",
 "options":[{"label":"...","sub":"..."}],
 "correct":[0,1,3],
 "successNote":"...","missNote":"Before Friday you still need: ","to":"n3"}

evaluate - free text against a visible rubric. Criteria light up as they are met. Routes to toPass or toFail.

{"type":"evaluate","step":3,"scene":"data","prompt":"...",
 "criteria":[{"label":"Names the specific channel",
              "keywords":["sms","email","in-app"],
              "hint":"say which channel actually fires"}],
 "pass":3,"passNote":"...","toPass":"good","toFail":"partial"}

showRubric: true starts the rubric expanded. Default is collapsed behind the e button, so the criteria are not on screen when you are projecting or screen-sharing. Press e after pasting an answer to reveal the ticks.

The i button - context on demand

Every choice, multi, evaluate and ending node carries an i button. It opens what the learner has seen so far - briefing text and the consequences of their own decisions - so nobody has to scroll back while writing. The engine assembles it automatically; you only add context when you want to inject something extra.

"context":[{"label":"Policy note","text":"Refunds over 5000 need a second approver."}]

Grading is client-side keyword matching, deliberately. An API key in a shareable file is an exposed key. In a live session the rubric on screen is the artifact - you grade in the room.

Endings

{"step":4,"scene":"launch","title":"...","moral":"one line, italic",
 "verdict":"what actually happened",
 "revealed":[["The probe","what the learner did and why it mattered"]],
 "media":[]}

Media links

Any node takes a media array. Links, never embeds - the file stays small and portable.

"media":[{"type":"ppt","label":"Case pack","url":"https://..."},
         {"type":"video","label":"2-min setup","url":"https://..."}]

Scenes

Procedural backdrops, no art needed: stage river office data conflict team ai matrix launch storm. Unknown names fall back to stage.

What the validator checks

  • Every to, toPass, toFail resolves to a real node or ending
  • No unreachable nodes or orphan endings
  • Every rubric criterion has keywords - one without them can never be met
  • Every gated wrong answer carries a coaching note
  • Every ending has a verdict

Theme

Every exported file carries a dark and a light theme, toggled from the sun icon in the header and remembered per device. Light is a white and blue scheme for projectors and printed handouts. Scene art follows the theme automatically - it is drawn from the same tokens as the text.

Layout

The scene is a banner, capped at roughly a fifth of the viewport, so the words get the page. If you are writing long narrative text, that is the ratio to design for - do not expect the picture to carry meaning it cannot carry.

Classroom

Each run ends with a copyable summary in plain sentences, with a compact code as the last line:

The Requirement That Wasn't - Business analysis scenario
Chose: Ask ops for a concrete case
Gap check: 3/3 of the must-haves
Written answer: 2/3 rubric criteria, short on who owns the call when it fails
Ending: Better, but still readable two ways
PUP|signoff|B>0+1+3(3/3)>written(2/3)|partial

Students drop it in the class channel. You read decisions, not just endings, and the debrief runs off what actually happened in the room.
