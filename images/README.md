# images

Pictures for scenarios. Anything in this folder is served by GitHub Pages at:

    https://gsj24983.github.io/puppeteer-sbl/images/<file name>

Paste that link into a scenario's **Your own picture** field (the banner) or into an **image** visual block (`src`).

## Adding a picture

1. On github.com, open this folder and choose **Add file > Upload files**.
2. Drop the picture in, then **Commit changes** (straight to `main` is fine).
3. Wait a minute or two for Pages to publish it, then open the link in a browser. If you see only the picture, the link is ready.

## Guidelines

- **Names:** lower case, hyphens, no spaces - `airline-call-centre.jpg`, not `Airline Call Centre (1).JPG`. The link is case-sensitive.
- **Format:** `.jpg` for photos, `.png` for screenshots and diagrams, `.webp` for either. Keep each file under about 300 KB so it loads on a phone.
- **Banner pictures** are cropped to a wide strip - use something roughly 4:1, for example 1600 x 400. Images inside the text are shown whole.
- **This repo is public.** Anyone with the link, or anyone browsing the repo, can see these files. Use only pictures you have the right to share, and nothing confidential.
